# PR 检查项

这份文档是平台中立的 PR 模板正文。无论项目托管在 GitHub 还是 GitLab，都可以复用这里的内容。

## 这次改动属于哪一类？

- [ ] 纯逻辑变更
- [ ] 页面交互变更
- [ ] 核心业务流程变更
- [ ] 强制更新相关变更

## 测试情况

- [ ] 已补单测
- [ ] 已补集成测试
- [ ] 需要 E2E 的功能已补 E2E
- [ ] 已在真机或模拟器上验证

## 文档和配置

- [ ] 已更新相关文档
- [ ] 已同步 `.env` / 配置说明
- [ ] 已确认 iOS / Android 跳转地址正确

## 备注

- 这次改动如果属于强制更新、登录、支付、数据保存等关键流程，默认需要更高一层的测试覆盖。
